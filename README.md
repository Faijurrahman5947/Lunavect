## 🛠️ Troubleshooting

### Lunavect Doesn't Detect My AI Assistant

**Solution:** Make sure both Claude Code and Codex are properly installed and running at least once. Then quit and restart Lunavect.

### My Sessions Aren't Showing Up

**Solution:** Check if your AI tools are configured in a standard location. Lunavect looks in the default installation paths. If you installed them elsewhere, try reinstalling them in their default locations.

### Notifications Aren't Working

**Solution:** Go to System Preferences → Notifications and make sure Lunavect is allowed to send notifications. Sometimes macOS blocks notifications for new apps until you approve them.

### The Menu Bar Icon Disappeared

**Solution:** Click on the Control Center icon (the toggle switch) in your menu bar, then look for Lunavect there. You can re-enable it from that menu.

### My Mac Won't Open Lunavect

**Solution:** Right-click the Lunavect icon in Applications, select "Open" from the context menu, then confirm "Open" again when prompted. This is a one-time security check from macOS for downloaded apps.
